# Premier League Player Analysis

## 概要
プレミアリーグ選手データを用いて、
シュート数・ゴール数・決定力・年齢・ポジションの関係を分析した。

## 使用技術
- Python
- pandas
- matplotlib
- Google Colab

## 分析内容
- シュート数とゴール数の相関
- ポジション別ゴール数分析
- 決定力(finishing)の算出
- 年齢と決定力の関係

## 主な結果
- FWは他ポジションより平均ゴール数・決定力が高かった
- シュート数とゴール数には強い正の相関が見られた
- 年齢と決定力の相関は弱かった
